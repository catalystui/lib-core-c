# API Reference

Reference documentation for the public APIs of CatalystUI Core. Each module has a single reference page containing its types, constants, functions, and operation results, as applicable.

| Module | Description |
| --- | --- |
| [CATALYST](catalyst/index.md) | Foundational numeric types, text representations, and operation results. |
| [CATMMLIB](catmmlib/index.md) | Memory allocation, release, resizing, and byte operations. |
| [CATTELIB](cattelib/index.md) | Text encoding, decoding, string length, and conversion. |
| [CATRLLIB](catrllib/index.md) | Arrays, sets, maps, and stacks. |

For result definitions and status codes, see [CATALYST](catalyst/index.md#catalyst_result). Result values are written as `0xSSCCOODD` in field order, independent of host byte order.

The result tables describe the current implementation and follow the [revised FDEFSPEC](https://github.com/catalystui/specifications/blob/languages/md/lang/en-US/fdefspec/index.md).
