# API Reference

Reference documentation for the public APIs of CatalystUI Core.

| Module | Description |
| --- | --- |
| [CATALYST](catalyst/index.md) | Foundational numeric types, text representations, and operation results. |
| [CATTELIB](cattelib/index.md) | Text encoding, decoding, string length, and conversion. |
| [CATMMLIB](catmmlib/index.md) | Memory allocation, resizing, and byte operations. |
| [CATRLLIB](catrllib/index.md) | Set, Map, Array, File, Stream, Queue, Stack, Pool, HashSet, and HashMap. |
| [CATTRLIB](cattrlib/index.md) | Process and thread execution, bounded dispatch, and work selection. |
| [CATOOLIB](catoolib/index.md) | Addressable objects, members, fields, methods, properties, structures, classes, and interfaces. |
